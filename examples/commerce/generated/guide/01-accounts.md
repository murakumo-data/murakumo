## 1.1 Nothing to create: the warehouse is a file

**Why:** DuckDB keeps the whole warehouse in one file, `commerce.duckdb`, created the first time anything is written to it. Each environment with a database of its own gets its own file.

```bash
duckdb commerce.duckdb -c 'select 42'
```

**You should see:** `42`, and a new file `commerce.duckdb` in the project folder.
