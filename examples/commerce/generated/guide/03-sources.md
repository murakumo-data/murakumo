## 3.1 Land the tables nothing here fetches

**Why:** These raw tables have no connection in the model, so something else delivers them (a partner's export, another team's loader). Put their files where the loads of chapter 4 look: one folder per table, JSON lines, named `<table>_<run time>_0001.jsonl`, with the run's time as `YYYYmmddTHHMMSSffffffZ` (UTC) so each run's files sort together.
