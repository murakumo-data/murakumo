# 11. Troubleshooting

What usually goes wrong, and what to do about it.

| You see | What to do |
| --- | --- |
| `No files found that match the pattern` | A load ran before anything landed in its folder: fetch first (chapter 3). |
| A load runs but adds no rows | Its files were loaded before: `audit.loaded_files` remembers each by name. |
| `Contract enforced` errors in dbt | A mart's columns or types changed: the model and the contract must match; generate again. |
| Relationship tests fail on -1 | A dimension lost its unknown member: rebuild it before its facts. |
| Snowflake: `insufficient privileges` | The role lacks a grant from chapter 1; run the provisioning as an administrator. |
| Snowflake: masking policy errors | The role needs CREATE MASKING POLICY on the governance schema. |
| An incremental table misses rows | They arrived late: rebuild it with `--full-refresh`, or set lookback_hours. |
