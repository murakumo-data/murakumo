## 2.2 Read how dbt connects

**Why:** profiles.yml has an output per environment; each reads its credentials from the variables of chapter 1. Run dbt with `--target <environment>`.

generated/dbt/profiles.yml:

```yaml
# Generated by Murakumo. Do not edit: change the model, then run `murakumo generate`.
commerce:
  target: personal
  outputs:
    personal:
      type: duckdb
      path: '{{ env_var(''MURAKUMO_DUCKDB_PATH'', ''commerce.duckdb'') }}'
      schema: '{{ env_var(''MURAKUMO_SCHEMA'', ''personal'') }}'
      threads: 4
    dev:
      type: duckdb
      path: '{{ env_var(''MURAKUMO_DUCKDB_PATH'', ''commerce.duckdb'') }}'
      schema: '{{ env_var(''MURAKUMO_SCHEMA'', ''dev'') }}'
      threads: 4
    prod:
      type: duckdb
      path: '{{ env_var(''MURAKUMO_DUCKDB_PATH'', ''commerce.duckdb'') }}'
      schema: '{{ env_var(''MURAKUMO_SCHEMA'', ''prod'') }}'
      threads: 4
```
